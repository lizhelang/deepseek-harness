# @deepseek-ai/dsh-client-ui-production-studio

[English](README.md) | 中文

## 概述

这个浏览器插件在对话、轨迹、任务监控与运行策略中展示同一段对话流程，并在输入框上方提供可展开的监控条。绑定对话从正常聊天请求开始，不需要另点启动。监控与运行策略追踪当前状态，对话与轨迹按日志顺序保留已提交的检查点。Goal、Todo、附件粘贴与模型选择保留各自原有组件。应用没有演示任务或模拟进度。

## 使用本包

运行带有 AEA 案件视图时，任务监控与输入框上方的监控条优先显示该案件：阶段条（建案、基线、改进、比较、制造、交付）、候选与 Host 调用预算、当前最佳候选及分数、Host 列出的剩余结束条件与下一步、每个实际候选一行的搜索与制造结果，以及带 SHA-256 的选定交付文件。该视图是可信适配器对最新 Host 回执的投影，不授予任何证书。流程节点行移入默认折叠的诊断区。面板按钮会在对话中排入一条普通消息：用当前最佳候选出图、从已验证候选继续改进，或制造尚无制造结果的已验证候选。仅当案件尚未交付且没有原生结果未知时显示；请求的步骤是否合法仍由 Host 判断。

节点诊断（没有运行带案件视图时直接显示）先显示受阻或结果未知的任务，再显示等待依赖、执行中、暂停和默认折叠的已交付任务。每个工件只有一行，展开后显示 Agent 分支，再展开显示尝试记录与观察证据。分支暂停、恢复与未知结果核对携带任务修订号，调用真实 Host 方法。

已完成交付直接展示验证后的文件，包括绝对路径、字节数、SHA-256 和复制路径操作。这些条目只读取已完成交付分支的最新内部 `production_aea_evidence` 回执，不读取模型输出。几何、制造、保存文件和目标验证与工厂验收及实物回折分别标注。

恢复只适用于暂停任务。受阻对话的最后一个已结清失败 Agent，在执行预算仍有余量、没有结果未知或调用未结清的节点时显示“暂停任务”和“暂停分支”；Host 在重新开放节点前再次检查准入条件。修复能力后，先暂停再恢复同一任务。受阻对话保留诊断，可接受补充聊天输入，不用另开任务。

「运行策略」取代原来的流程图编辑器。它提供三个预设（快速出图、标准、深度优化），可调整搜索深度（基线即交付、有限个候选、搜到没有改进）、候选来源、制造范围（只制造最佳或制造前几个比较）、交付前确认，并只读说明 Host 评分方式。「应用到本对话」把策略作为一条普通聊天消息排入对话，对当前和之后的案件生效，因此有日志记录且模型可见；Host 冻结的候选上限（表单会显示最新案件的上限）、参数与交付检查仍约束每个案件。草稿保存在客户端 store 中，不持久化。没有对话 provider 的会话显示说明，不显示表单。

仅查看监控不会启动或重做历史工作。对话还没有任务时不显示监控条，连接中断时显示中断提示；计数包含等待和暂停的流程。只统计 Host 记录的流程，不统计普通聊天消息或工具调用，也不会自动补录历史执行。

早期版本的运行（例如独立调度的运行或修改过流程图的运行）仍在诊断区可见；Host 会拒绝对它们暂停和恢复。

<a id="understand-the-implementation"></a>
## 理解实现

`src/client/index.ts` 负责 Cordis effect 和 slot 注入。`production-source.ts` 按修订顺序追踪当前 Host 状态并保留会话引用。`checkpoint.ts` 为 `production/checkpoint` 注册独立的对话与轨迹 Definition，以日志序号而非运行 ID 为键，因此每条完整运行记录都可独立回放。对话展示本地化流程卡片。轨迹使用[业务记录扩展](../ui-trajectory/README.zh.md#business-records)渲染本地化摘要，并在 Payload 中展示检查点的完整运行数据，不开启第二条历史流。`stores.ts` 只负责未提交界面状态。组件接收 props 而非 Cordis context，文案与 CSS 使用现有语言和主题组件。

没有发布 `./invariant` 附件：本包只负责展示和明确的用户操作，没有一份可能独立偏离执行状态的第二观察。生产执行证据与准入由 `dsh-production-studio` 负责。

<a id="model-experience"></a>
## 模型体验

### 案件操作与运行策略

#### 模型所见

这个界面不提供提示章节或工具 schema。案件按钮和「应用到本对话」把显示的文字作为一条普通用户消息排入对话，模型看到的与手动输入相同。暂停、恢复与核对调用 [Production Studio](../../workflow/production-studio/README.zh.md) 运行时的 `productionStudio.pause`、`productionStudio.resume` 和 `productionStudio.reconcile`，由它负责准入及模型可见性。

#### Token 影响

查看检查点与监控不会增加模型 token。排入的聊天消息与手动输入花费相同。UI 不会启动子 Agent。

#### KV Cache 影响

界面不会修改请求历史。历史卡片使用自身已提交的会话事件，排入的聊天消息与普通用户消息一样追加到历史。

## 已知限制与待完成工作

<a id="known-limitations-and-deferred-work"></a>

- **能力绑定：** 本界面不提供 AEA／Rhino 能力实现。任务快照列出当前 Host 的工具和文件系统能力。能力不可用或客观证据未绑定时，会显示明确诊断。
- **运行策略的作用范围：** 策略是一条对话请求，不是 Host 设置。模型在 Host 冻结的候选上限和交付检查内执行它；表单不能提高该上限。
- **轨迹展示：** 每行只描述自身已提交的检查点，不读取实时任务快照。Payload 检查器只读；打开历史记录不会恢复或重做执行。
